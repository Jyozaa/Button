# The Button

A tiny browser experiment where a single button gets progressively stranger the more you interact with it.

- Built with HTML/CSS/JavaScript
- Web Audio API for subtle, generative sound (no audio files)
- Press `M` to mute/unmute (preference is remembered)

## Run locally

Just open `index.html` in a browser. No build step, no dependencies.

```sh
open index.html
```
